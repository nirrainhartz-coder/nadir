# נדיר 🤿 — משחק צלילה מרובה משתתפים

## הרצה
1. התקינו Node.js (גרסה 18 ומעלה). אין צורך ב-npm install.
2. בתיקייה הזו: `node server.js`
3. במחשב (ההוסט) פתחו את הכתובת http://localhost:3000 — כל מה שמוצג שם הוא המסך הגדול.
4. השחקנים מתחברים לאותה רשת Wi-Fi ופותחים בטלפון את הכתובת שמופיעה על המסך (http://<IP>:3000/play).
5. ההוסט לוחץ "התחילו", ואחרי כל שאלה "לשאלה הבאה" (אפשר גם רווח/Enter).

## ניקוד
נפוץ 10 • בינוני 20 • נדיר 35 • אגדי 50, ועוד 10 בונוס למי שתשובתו ייחודית בחדר. כל נקודה = 10 מטר.

## עריכת שאלות
הכל בקובץ questions.js: לכל שאלה ארבע רשימות (c/m/r/l). אפשר להוסיף כינויים עם |.
תשובה שלא ברשימה (גם אם היא נכונה) תידחה כ"לא מתאים לנושא", אז כדאי להרחיב את הרשימות.
